PROJETO: OTIMIZAÇÃO DE ROTAS - COZINHA PILOTO

Discente: Luiz Francisco Charleaux e Caetano
Problema Tratado: Aplicação do Algoritmo do Caixeiro Viajante (TSP) 
para otimização das rotas de entrega de alimentos da Cozinha Piloto 
de Cachoeira Paulista.

O projeto foi desenvolvido em Python utilizando a biblioteca Streamlit 
para a interface gráfica, seguindo o princípio de separação de 
responsabilidades (Modularização). O código-fonte está dividido em 5 arquivos:

1. app.py: Arquivo principal que gerencia a interface web, os menus e a interação com o usuário.
2. gerador_problema.py: Responsável por criar a matriz de distâncias (fixa ou aleatória) e gerar a solução inicial, respeitando a regra de roteamento fixo quando exigido.
3. avalia_sucessor.py: Contém a função de avaliação de custo da rota e o motor de geração de vizinhos (sucessor), garantindo a integridade dos pontos de origem e destino (Cozinha Piloto).
4. logica.py: Contém a implementação matemática pura dos algoritmos heurísticos de busca (Subida de Encosta Clássica, Subida de Encosta com Tentativas e Têmpera Simulada).
5. analise_comparativa.py: Motor de automação que executa múltiplas baterias de testes com os algoritmos e gera os dados da "Tabela 1", calculando a porcentagem de Ganho de cada método.


Para rodar a aplicação em sua máquina local, siga os passos abaixo:

1. Certifique-se de ter o Python instalado (versão 3.8 ou superior).

2. Abra o terminal na pasta do projeto e instale as bibliotecas individualmente:

   # Instala o framework da interface web
   pip install streamlit

   # Instala a biblioteca para cálculos matemáticos e matrizes
   pip install numpy

   # Instala a biblioteca para geração e manipulação de tabelas
   pip install pandas

3. Após as instalações, inicie a aplicação com o comando:
   streamlit run app.py

4. O sistema abrirá automaticamente uma aba no seu navegador padrão (geralmente no endereço http://localhost:8501). 

6. Guia de operação da interface:
   Para realizar um teste completo, siga esta sequência obrigatória:

   A) CONFIGURAÇÃO DO PROBLEMA:
      - No menu lateral, escolha entre "FIXO" ou "ALEATÓRIO".
      - No modo "FIXO", o sistema utiliza a matriz real da Cozinha Piloto.
      - No modo "ALEATÓRIO", você pode definir a quantidade de escolas para o teste.
      - Clique no botão "GERAR PROBLEMA" para criar a matriz de distâncias.

   B) SOLUÇÃO INICIAL:
      - Clique no botão "SOLUÇÃO INICIAL" para definir o ponto de partida.
      - Nota: No modo "FIXO", a solução inicial é constante conforme exigido. No "ALEATÓRIO", ela é gerada de forma randômica.

   C) EXECUÇÃO DE ALGORITMOS:
      - No campo "Selecione o Método", escolha o algoritmo desejado (SE, SET ou TE).
      - Caso escolha SET ou TE, campos adicionais para parâmetros (como TMAX ou Temperatura) aparecerão automaticamente.
      - Clique em "EXECUTAR MÉTODO" para ver a melhor rota encontrada e a distância final.

   D) ANÁLISE COMPARATIVA (TABELA 1):
      - Selecione a opção "Análise Comparativa".
      - Ao clicar em "EXECUTAR MÉTODO", o sistema rodará automaticamente todas as 11 configurações exigidas na atividade.
      - O resultado será exibido em uma tabela comparativa com o cálculo do "Ganho" percentual de cada método.
